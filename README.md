# AI-Powered ATS Resume Analyzer

An intelligent resume parsing and optimization engine built using Streamlit and Google Gemini 1.5 Flash. It checks resumes against target job criteria to maximize hiring viability.

## ⚙️ Local Setup Instructions

1. Clone or download this project folder.
2. Initialize your local setup dependencies via terminal:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application layer locally:
   ```bash
   streamlit run app.py
   ```
